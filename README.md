# 🌐 AmanDevspace — Personal Portfolio Website

Welcome to the source code for my personal portfolio website! This project showcases my recent web development projects, interactive features, and technical skill set.

## ✨ Key Features
- **Glassmorphic UI:** Sleek, modern dark-mode aesthetic with custom animations.
- **Dynamic LeetCode Stats:** Fetches real-time coding stats via GraphQL API integration.
- **Functional Contact Form:** Asynchronous POST requests powered by a Node.js/Express backend with Nodemailer.
- **Certificate Modal & Interactive Carousels:** Smooth client-side user experience.

## 🛠️ Built With
- **Frontend:** HTML5, Modern CSS, Vanilla JavaScript
- **Backend:** Node.js, Express.js, Axios, Nodemailer, CORS
- **Hosting:** Netlify (Frontend) & Render (Backend)
